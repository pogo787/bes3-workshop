Read. Configure.
Document.

Connect your eBike via a USB data cable. BES3 Workshop reads all key component and diagnostic data, unlocks the bike light output, configures light wattage and service intervals, checks System IDs, and exports a multi-page PDF diagnostic report. Every write is automatically re-read from the bike and verified.

or – offline, no bike required

This browser does not support WebUSB. Please use Chrome or Edge on Windows, macOS, or Linux. Demo mode and opening saved readouts still work.

  1. 1

    Power on the eBike

    The system must be switched on. Close any other diagnostic tabs or software first.

  2. 2

    Plug in a USB data cable

    Connect to the USB-C port on the control unit. A charge-only cable will not work.

  3. 3

    Pair in the browser

    Click “Connect eBike via USB” and select the controller in the browser prompt.

  4. Unofficial open-source tool, not affiliated with Bosch. Reading is strictly passive. Writes only occur after your explicit confirmation.
